# Levantamento dos requisitos Funcionais e Não Funcionais.
## Requisitos Funcionais

RF01: Cadastro de Alunos <br>
O sistema deve permitir ao professor o cadastro de novos alunos com informações básicas
(nome, idade, telefone, endereço, peso, altura, sexo).

RF02: Cadastro de Aulas <br>
O sistema deve permitir ao professor cadastrar aulas com data, horário e descrição das
atividades.

RF03: Exibição de Agenda <br>
O sistema deve permitir que os alunos visualizem os dias e horários das aulas cadastradas.

RF04: Registro de Presença <br>
O sistema deve permitir que o aluno indique presença em uma aula através de um botão
(“Compareci”).

RF05: Validação de Presença <br>
O professor deve poder aprovar, rejeitar ou corrigir registros de presença realizados pelos alunos.

RF06: Histórico de Participação <br>
O sistema deve armazenar o histórico de presenças dos alunos para consulta posterior.

RF07: Acompanhamento de Dados Pessoais <br>
O aluno deve poder visualizar seus dados pessoais e seu histórico de frequência. Quando houver atualização de peso ou medidas, o sistema poderá exibir a evolução de forma gráfica.

RF08: Emissão de Avisos <br>
O professor deve poder emitir avisos ou comunicados que são exibidos para todos os
alunos cadastrados da turma.

RF09: Notificações <br>
O sistema deve exibir notificações internas sobre novas aulas e avisos publicados.

RF10: Login Simplificado <br>
O sistema deve permitir o acesso por meio de autenticação simples (telefone e senha ou
PIN).

RF11: Perfis de Usuário <br>
O sistema deve diferenciar perfis de aluno e professor, exibindo funcionalidades
específicas para cada tipo.

RF12: Cadastro Manual de Presença <br>
O sistema deve permitir que o professor registre manualmente a presença de alunos caso
necessário.

RF13: Gerenciamento de Turmas <br>
O sistema deve permitir a criação e gerenciamento de turmas pelo professor.

RF14: Visualização de Relatórios <br>
O professor deve poder visualizar relatórios básicos com número de alunos ativos e
presenças mensais.

RF15: Atualização e Exclusão de Cadastros <br>
O sistema deve permitir ao professor editar ou excluir registros de alunos, aulas, turmas e avisos quando necessário.

RF16: Consulta de Alunos <br>
O sistema deve permitir ao professor consultar a lista de alunos cadastrados, com possibilidade de visualizar dados individuais.

## Requisitos não funcionais
RNF01: Acessibilidade <br>
O sistema deve ter botões grandes, letras legíveis e ícones intuitivos, visando o público
idoso.

RNF02: Usabilidade <br>
A interface deve ser simples e com poucos passos.

RNF03: Portabilidade <br>
O sistema deve funcionar em dispositivos Android e iOS, priorizando smartphones.

RNF04: Desempenho <br>
O aplicativo deve carregar a tela principal rapidamente em conexão 3G.

RNF05: Armazenamento Offline <br>
O sistema deve prever armazenamento local temporário para consulta de informações básicas em caso de instabilidade na internet.

RNF06: Segurança <br>
Os dados dos usuários devem ser armazenados de forma segura, respeitando os princípios
da LGPD.

RNF07: Escalabilidade <br>
O sistema deve permitir a adição de novos grupos e turmas sem reconfiguração manual.

RNF08: Compatibilidade <br>
O sistema deve ser compatível com versões do Android 8.0 ou superior e iOS 13 ou
superior.

RNF09: Responsividade <br>
A interface deve se ajustar automaticamente a diferentes tamanhos de tela.

RNF10: Manutenibilidade <br>
O código deve ser modular para facilitar futuras atualizações e correções.

RNF11: Notificações Simples <br>
As notificações devem ser claras e diretas, sem exigir interação complexa do usuário.

RNF12: Idioma <br>
Todo o conteúdo deve estar em português e utilizar linguagem clara e objetiva.
