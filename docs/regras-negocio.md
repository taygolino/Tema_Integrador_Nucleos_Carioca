# Levantamento das Regras de Negócio
**RN01**: Apenas professores podem cadastrar, editar ou excluir alunos, aulas, turmas e avisos.

**RN02**: Alunos podem visualizar a agenda, consultar seus próprios dados e registrar presença nas aulas.

**RN03**: Cada aluno deve estar vinculado a pelo menos uma turma.

**RN04**: Cada aula deve estar vinculada a uma turma.

**RN05**: A presença registrada pelo aluno deve ficar pendente até validação do professor.

**RN06**: O professor pode aprovar, rejeitar ou corrigir uma presença registrada.

**RN07**: Um aluno não pode registrar presença duplicada na mesma aula.

**RN08**: Avisos devem ser associados a uma turma ou publicados para todos os alunos.

**RN09**: O telefone deve ser único para cada usuário, pois será usado no login simplificado.

**RN10**: Relatórios devem considerar apenas alunos ativos.

**RN11**: Os dados pessoais dos alunos devem ser acessíveis apenas pelo próprio aluno e pelo professor responsável.

**RN12**: O sistema deve manter histórico das presenças mesmo após alterações cadastrais.
